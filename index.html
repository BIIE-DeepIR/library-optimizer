Library Optimizer

Plan and optimize pooled variant libraries for genome engineering. Estimate unique variant coverage from transfection parameters and Poisson occupancy, then step through five experimental checkpoints: culture expansion volume, freeze-down vial counts (1×–3× backups), FACS/MACS sort yield, PCR template copies per variant, and NGS sequencing depth — with kit recommendations for MiSeq i100, MinION, and ETH Basel instruments. Supports HDR via Cas9, serine integrase landing-pad insertion (Bxb1, PhiC31), and multiple cell types including yeast.

Library capture — how this is computed
N = cells x transfections x viability x efficiency U = L x ( 1 - e^(-N/L) ) cov = N / L pct = U / L x 100
—
L = designed library size · N = cells carrying an integration. Poisson occupancy: integrations land at random, so some variants are hit repeatedly while others are missed. Capture saturates at L — more cells raise coverage, never diversity beyond the library itself.

FACS / MACS sort — how this is computed
gated = U x C x h recovered = gated x r U_capt = U x h x [ 1 - (1 - r)^C ]
—
h = hit rate · r = per-cell recovery. A variant enters the gate with C copies, so it is only lost if every copy is lost — hence the survival term rather than a flat x r.

PCR amplification — how this is computed
copies/variant = recovered / U_capt gDNA_total = recovered x m / 1000 rxns = ceil(gDNA_total / L_rxn) gDNA_min(k) = U_capt x k x m / 1000 dropout = e^(-k)
—
m = pg gDNA per genome · L_rxn = ng loaded per reaction · k = mean copies per variant carried into the PCR. Poisson dropout: one cell = one genome equivalent = one copy of one variant.

reads_target = U_capt x R runs = ceil(reads_target / reads_per_run)
